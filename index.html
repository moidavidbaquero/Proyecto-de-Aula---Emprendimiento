Newton-Raphson — Base matemática
Fórmula de iteración:
xₙ₊₁ = xₙ − f(xₙ) / f'(xₙ)

Dado el punto inicial x₀, el método construye la recta tangente a f en ese punto y toma su raíz como siguiente aproximación. Repite hasta que |xₙ₊₁ − xₙ| / |xₙ₊₁| < ε.

Derivada numérica (diferencias centradas):
f'(xₙ) ≈ [f(xₙ+h) − f(xₙ−h)] / 2h

Convergencia: Cuadrática cuando f'(x*) ≠ 0. Cada iteración duplica los dígitos correctos.

Aplicación en EquilibraDB: f(q) = T(q) − T_max, donde T(q) es el tiempo de respuesta interpolado para q consultas concurrentes. La raíz q* es el punto exacto de saturación de la base de datos.

¿Por qué Newton aquí? La curva T(q) es monótona creciente y suave — tiene derivada bien definida — lo que garantiza convergencia rápida de Newton.

Müller — Base matemática
Construcción de parábola:
Dados (x₀,f₀), (x₁,f₁), (x₂,f₂):
p(x) = a(x−x₂)² + b(x−x₂) + c
Nueva aproximación:
x₃ = x₂ − 2c / (b ± √(b²−4ac))
(signo que maximiza el denominador)

Si b²−4ac < 0, la raíz es compleja. Una raíz compleja en g(t) indica que la variación del tiempo de respuesta tiene un comportamiento oscilatorio inestable.

Convergencia: Superlineal, orden ≈ 1.84. No requiere derivada analítica.

¿Por qué Müller aquí? La serie temporal de variaciones ΔT(t) tiene picos abruptos y comportamiento irregular. Newton fallaría por derivadas nulas o discontinuas. Müller es robusto ante estas irregularidades y puede detectar las oscilaciones mediante raíces complejas.
